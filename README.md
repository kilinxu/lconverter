# Convert link to IP Address program
Python 3.9 is required to be installed on your system.
A simple Python script that takes a link and converts it into an IP Address, for the curious minded people
This program isn't intended for professional use, but rather a small learning project for myself and for people who care what each link looks like as an IP Address
you can only put link domains in(so no: example.com/this)
## IMPORTANT: only IPv4 output is supported.
Direct copy link are supported, my Python program supports https://example.com/ or http://example.com/, so you can copy the link straight off and won't have to edit it yourself into example.com
My Python program already contains a shebang, you can just make it executable(chmod +x) and put it in your exec folder(optional)

*example output with args https://google.com/ https://github.com/:*
google.com: 142.250.185.78
github.com: 140.82.121.4
